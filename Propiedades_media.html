Propiedades de la media aritmética

La media x̄ = Σ fixi es el punto de equilibrio de los datos cuando cada valor xi pesa su frecuencia relativa fi. Arrastra las pilas de puntos para mover los datos; las cuatro láminas usan los mismos datos.

Datos

Los datos y su punto de equilibrio

Proposición 1.5.1

La media está entre los extremos

Si la variable toma al menos dos valores distintos, x1 < xk ⟹ x1 < x̄ < xk.

Las aportaciones fi(xi − x1) se colocan una tras otra desde x1 y terminan exactamente en x̄; las aportaciones fi(xk − xi) hacen lo mismo desde xk. Ninguna es negativa y la de xk (o la de x1) es positiva, así que la media no puede tocar los extremos.

Proposición 1.5.2

Las desviaciones se compensan

Σ ni(xi − x̄) = Σ fi(xi − x̄) = 0

Toca o arrastra en la lámina para mover el apoyo p. El balancín gira según Σ fi(xi − p) = x̄ − p.
Proposición 1.5.3

La media sigue a las transformaciones afines

yi = a xi + b ⟹ ȳ = a x̄ + b

Con los dos ejes a la misma escala, las rectas que unen cada x con ax + b pasan todas por un mismo punto, el centro de la homotecia c = b/(1 − a). La de la media también: la transformación arrastra el punto de equilibrio. Con a = 1 son paralelas (traslación) y con a < 0 se cruzan entre los ejes (el orden se invierte).

Proposición 1.5.4

La media minimiza los cuadrados de las desviaciones

Σ fi(xi − x̄)² < Σ fi(xi − a)² para todo a ≠ x̄

Toca o arrastra en cualquiera de las dos láminas para mover a. A la derecha: M(a) = s² + (a − x̄)², una parábola con mínimo en x̄.
